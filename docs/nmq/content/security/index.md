# Security

NCP 当前已经包含若干基础安全能力，但也明显依赖部署时的环境约束。

## 已实现的安全能力

- HTTPS 监听与证书加载
- 登录验证码
- JWT 私有路由鉴权
- 用户、角色、资源相关 API
- 证书信息存储模型

## 需要部署侧补齐的部分

- 证书轮换机制
- 密钥托管
- API 暴露范围控制
- SQLite 文件与产品包目录权限
- 日志中的敏感信息脱敏

## 最值得先做好的四件事

1. 仅通过 HTTPS 暴露需要认证的 API。
2. 使用独立签名密钥和受控证书目录。
3. 把 `data/`、`packages/`、`tmp_pkg/` 放到受控可写卷。
4. 对 WebUI 和私有 API 做网段或网关层访问控制。

## 仓库现状说明

截至 2026-07-27，这个仓库里还没有独立的安全策略文档，因此安全边界主要依赖源码和部署约束来理解。
